# Original synthetic network

`network.geojson` and `structures.geojson` are an invented branched network around geographic (0, 0), generated by `node scripts/generate-network.mjs`. The location, IDs, conductor names, physical attributes, and layout are fictional. No imported base geography, utility geometry, operational records, internal service, or proprietary data was used.

39 spans connect 40 supports. Three illustrative conductor families vary mass, tension, length, and damping. Names are generic educational labels, not conductor specifications. Reference temperature is 20 °C. Initial sag uses the simple parabolic gravity relationship only as a demonstration starting point. All values are validated against broad demonstration bounds.

`SpanDataSource` operates on normalized plain data, independently of GIS rendering. The bundled adapter reads GeoJSON, validates connectivity/IDs/geometry, and returns isolated copies. Source data is recursively frozen. Extent filtering uses intersection with the span's geographic bounding box; a future service adapter can refine that query.

`lengthSource` chooses either `provided` engineering length or `geometry` length. Geometry length sums spherical great-circle segment lengths with a 6371008.8 m radius. The synthetic records use geometry length and remain consistent with endpoints; the selected card discloses the source and any length override. Frequencies and resonance response are never persisted.

The authorized-data adapter boundary is deliberately a type/interface only. No real-data adapter, credentials, internal URLs, telemetry, or operational identifiers are included.
